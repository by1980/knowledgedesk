How do I connect Gmail / Google Workspace?
  1. The mailbox needs 2-Step Verification turned on: open this page while signed in to that mailbox.
  2. Create an app password: myaccount.google.com/apppasswords → name it "KnowledgeDesk" → copy the 16-letter password.
  3. Here, use server imap.gmail.com, port 993, the full email address, and the app password.
  4. Folders: INBOX, and for sent mail add [Gmail]/Sent Mail. Use "Test connection" to see all folder names.

Other providers: use their IMAP settings (server, port 993). Microsoft 365 / Outlook.com mailboxes need a different sign-in method that is coming in the next version.

Where do I find the calendar link?

Google Calendar: on a computer, open Google Calendar → ⚙️ Settings → click the calendar on the left under "Settings for my calendars" → scroll to Integrate calendar → copy Secret address in iCal format.

Outlook / Microsoft 365: Outlook on the web → ⚙️ Settings → Calendar → Shared calendars → Publish a calendar → choose "Can view all details" → Publish → copy the ICS link.

WhatsApp doesn't allow other apps to read chats directly, so chats are added by exporting them:

  1. On the phone, open the chat or group → tap its name (iPhone) or ⋮ menu → More (Android) → Export chat.
  2. Choose Attach media to include voice notes (they will be transcribed), or Without media for text only.
  3. Send the file to yourself (email, or save to Files / Drive) and upload it in Documents → Add knowledge.

Re-export and upload the same chat later to update it.
